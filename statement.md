# Project Statement

## Project Title
Student Expense Tracker – A Java-Based Personal Expense Management System

## Problem Statement
Students often makes small daily payments for food, travel, stationery, entertainment, and other activities. When these expenses are not recorded systematically, it becomes difficult to know  that where the total amount spent or identify the categories where most money is being used.

The proposed system provides a simple command-line Java application for recording and analysing student expenses.

## Scope
The project covers:
- Recording individual expenses.
- Viewing stored expenses.
- Searching expense records.
- Deleting records.
- Calculating basic expense statistics.
- Saving and loading records using a local text file.
- Input validation and basic error handling.

The current version does not include online accounts, cloud storage, payment processing, or a graphical user interface.

## Target Users
- College students
- Students who want a simple personal expense record
- Beginners learning Java and object-oriented programming

## High-Level Features which I have added
1. Add Expense.
2. View All Expenses.
3. Search Expense.
4. Delete Expense.
5. Expense Report.
6. Local File Storage.
7. Input Validation.
8. Basic Automated Tests.
